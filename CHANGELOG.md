# Changelog

## 0.1.0

- Refactored the project into the `auto_report` Python package.
- Added the `auto-report` CLI with `daily`, `monthly`, `generic`, and `count` commands.
- Added natural image sorting, YAML/TOML/JSON configuration, presets, typed modules, and clearer errors.
- Added a general-purpose LTR report example while preserving the Arabic facility preset.
- Added pytest coverage, Ruff linting configuration, and GitHub Actions CI.
- Replaced the script-focused README with portfolio-oriented documentation.
